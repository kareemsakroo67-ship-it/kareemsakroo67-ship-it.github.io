VOLT

موقع متجر إلكترونياتElectronics store website

المشكلةThe problem

متجر إلكتروني محتاج فلاتر واضحة وسلة وخطوات دفع مطمئنة.An online store needs clear filters, a cart and checkout steps that feel trustworthy.

اللي بنيتهWhat I built

فلاتر وترتيب للمنتجات، سلة، دفع تجريبي ولوحة طلبات. من غير دفع حقيقي.Product filters and sorting, a cart, a simulated checkout and an order dashboard. No real payments.

قراراتيDecisions

كله تجريبيEverything simulated

الدفع ولوحة الطلبات تجريبيين في المتصفح. مفيش دفع حقيقي ولا منتجات حقيقية والصفحة مكتوب فيها كده.Checkout and the order dashboard are simulated in the browser. No real payments or real products, and the page says so.

رسومات منتجات خاصةOwn product illustrations

المنتجات برسومات معمولة للنموذج وأسماء براندات خيالية، فمفيش براند أو صورة حقيقية متنسخة.Products use illustrations made for the demo and fictional brand names, so no real brand or photo is copied.

فلاتر وترتيبFilters and sorting

الفلاتر والترتيب JavaScript عادي على قايمة منتجات جوه الصفحة.Filters and sorting are plain JavaScript over a product list in the page.

اللي اتعلمتهWhat I learned

ده أكتر مشروع فيه ميزات، فاتعلمت أنظّم الكود: قايمة المنتجات والفلاتر والترتيب والسلة والدفع التجريبي. وضّحت إن مفيش حاجة حقيقية. البرتقالي اللي استخدمته مع النص الأبيض كان فاتح على القارئ، فاتعلمت أختبر التباين وأغمّقه.This is the project with the most features, so I learned to keep the code organised: product list, filters, sorting, cart and a simulated checkout. I made it clear that nothing is real. The orange I used for white text was too light for readers, so I learned to test colour contrast and darken it.

تحدي تقنيA technical challenge

قايمة المنتجات لازم تترتب في المتصفح بالسعر أو التقييم من غير ما نغيّر القايمة الأصلية، عشان الفلاتر تفضل شغالة بعد الترتيب.The product list has to be sorted in the browser by price or rating without changing the original list, so the filters can still work after sorting.

if(S.sort==="lo")a.sort((x,y)=>x.p-y.p);
else if(S.sort==="hi")a.sort((x,y)=>y.p-x.p);
else if(S.sort==="rt")a.sort((x,y)=>y.r-x.r);

حدود المشروعLimits

ده نموذج تجريبي لطالب: مش عميل حقيقي ومفيش مبيعات أو مستخدمين حقيقيين. الأدوات: HTML وCSS وJavaScript بس.This is a student concept: no real client, no real sales or users. Built with HTML, CSS and JavaScript only.
