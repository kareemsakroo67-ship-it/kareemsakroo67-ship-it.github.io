TAQS

صفحة طقس (API حقيقي)Weather page (live API)

المشكلةThe problem

الناس عايزة توقعات طقس سريعة وواضحة لمدينتها بالعربي أو الإنجليزي.People want a quick, clear forecast for their city in Arabic or English.

اللي بنيتهWhat I built

الطقس الحالي وتوقعات 5 أيام من Open-Meteo API المجاني (من غير مفتاح)، بحث عن مدينة، وزرار عربي/إنجليزي.Current weather and a 5-day forecast from the free Open-Meteo API (no key), city search, and an Arabic/English switch.

قراراتيDecisions

API مجاني من غير مفتاحA free API with no key

Open-Meteo مش محتاج مفتاح API، فمفيش أسرار في الصفحة. الطقس والبحث بيتطلبوا من المتصفح مباشرة.Open-Meteo needs no API key, so nothing secret sits in the page. Weather and city search are called straight from the browser.

التعامل مع الأخطاءHandle failures

لو النت أو الـ API وقعوا، الصفحة بتعرض رسالة بسيطة بدل شاشة فاضية.If the network or the API fails, the page shows a plain message instead of a blank screen.

ذكر مصدر البياناتCredit the data

بيانات Open-Meteo رخصتها CC BY 4.0، فالصفحة بتذكرها برابط.Open-Meteo data is CC BY 4.0, so the page credits it with a link.

اللي اتعلمتهWhat I learned

في المشروع ده استخدمت API عام حقيقي. اتعلمت أجيب البيانات في المتصفح، وأعرض رسالة لو فشل، وأذكر مصدر البيانات. وشفت كمان إن التواريخ والأرقام محتاجة انتباه بين العربي والإنجليزي، فالصفحة بتعرضها حسب اللغة المختارة.In this project I used a real public API. I learned to fetch data in the browser, show a message when it fails, and credit the data source. I also saw that dates and numbers need care in Arabic and English, so the page formats them for the chosen language.

تحدي تقنيA technical challenge

الـ API الحي ممكن يفشل أو يبقى بطيء. الصفحة مينفعش تفضل فاضية، فلو الطلب فشل بتظهر رسالة بسيطة باللغة المختارة.A live API can fail or be slow. The page must not stay blank, so a failed request shows a plain message in the chosen language.

حدود المشروعLimits

ده نموذج تجريبي لطالب: مش عميل حقيقي ومفيش مبيعات أو مستخدمين حقيقيين. الأدوات: HTML وCSS وJavaScript بس.This is a student concept: no real client, no real sales or users. Built with HTML, CSS and JavaScript only.
