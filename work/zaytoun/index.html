المشكلةThe problem

مطعم أكل بيتي محتاج منيو واضح على الموبايل وطريقة سهلة لحجز طاولة.A home-style restaurant needs a menu that reads well on a phone and an easy way to book a table.

اللي بنيتهWhat I built

منيو بتبويبات، طبق اليوم، ونموذج حجز طاولة بيبعت التفاصيل على واتساب.Tabbed menu, dish of the day and a table booking form that sends the details to WhatsApp.

قراراتيDecisions

المنيو بتبويباتMenu in tabs

المنيو متقسم لأقسام عشان اللي على الموبايل يوصل للطبق بضغطة.The menu is split into categories so people on a phone reach a dish in one tap.

الحجز عبر واتسابBooking through WhatsApp

طلب الطاولة بيفتح رسالة واتساب جاهزة لأن الموقع الثابت مفيهوش سيرفر يخزّن الحجوزات.Table requests open a ready WhatsApp message, since a static site has no server to store bookings.

اللي اتعلمتهWhat I learned

المشروع ده علّمني أعمل منيو سهل على الموبايل بالتبويبات. واتعلمت كمان أذكر مصادر الصور صح: الصور من Wikimedia Commons ومصادرها مكتوبة في المشروع. ولما راجعت الألوان لقيت إن شوية نصوص رمادي فاتحة ومش مريحة في القراءة، فخليتها أغمق.This project taught me how to make a menu easy to use on a phone with tabs. I also learned to credit photos properly: they come from Wikimedia Commons and the credits are in the project. When I checked the colours, I found some grey text was too light to read comfortably, so I made it darker.

تحدي تقنيA technical challenge

الموقع الثابت مفيهوش سيرفر، فالحجز أو الطلب مش بيتحفظ. النموذج بيجهّز رسالة واتساب جاهزة والشخص هو اللي يبعتها. لازم النص يتعمله encode عشان العربي والرموز تفضل سليمة في الرابط.A static site has no server, so a booking or order cannot be saved. The form builds a ready WhatsApp message and the person sends it themselves. The text has to be encoded so Arabic and symbols survive the link.

"https://wa.me/"+WHATSAPP+"?text="+encodeURIComponent(DEMO+t)
