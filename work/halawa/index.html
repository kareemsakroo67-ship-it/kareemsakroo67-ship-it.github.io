HALAWA BAYTNA

موقع محل حلوياتSweets shop website

المشكلةThe problem

محل حلويات بيتي محتاج منيو الناس تتصفحه وطريقة بسيطة للطلب.A home bakery needs a menu people can browse and a simple way to order.

اللي بنيتهWhat I built

منيو منتجات بفلتر، وسلة، وطلب بيفتح رسالة واتساب جاهزة.Product menu with filters, a cart and ordering that opens a ready WhatsApp message.

قراراتيDecisions

فلاتر وسلة بـ JavaScript عاديFilters and a cart in plain JavaScript

الفلاتر والسلة شغالين في المتصفح من غير مكتبات.Category filters and the cart run in the browser with no library.

الطلب عبر واتسابOrder by WhatsApp

الطلب بيفتح رسالة واتساب جاهزة بالمنتجات اللي في السلة لأن مفيش سيرفر ولا نظام دفع.The order opens a ready WhatsApp message with the cart items, because there is no server or payment system.

اللي اتعلمتهWhat I learned

اتعلمت أعمل فلاتر وسلة بـ JavaScript عادي، وأحوّل السلة لطلب واتساب جاهز لأن مفيش سيرفر. اللون الوردي اللي اخترته في الأول كان فاتح على النص، فاتعلمت أفحص التباين بين الألوان وأختار وردي أغمق.I learned to build filters and a cart with plain JavaScript, and to turn the cart into a ready WhatsApp order because there is no server. The pink I first chose was too light for text, so I learned to check colour contrast and pick a darker pink.

تحدي تقنيA technical challenge

الموقع الثابت مفيهوش سيرفر، فالحجز أو الطلب مش بيتحفظ. النموذج بيجهّز رسالة واتساب جاهزة والشخص هو اللي يبعتها. لازم النص يتعمله encode عشان العربي والرموز تفضل سليمة في الرابط.A static site has no server, so a booking or order cannot be saved. The form builds a ready WhatsApp message and the person sends it themselves. The text has to be encoded so Arabic and symbols survive the link.

"https://wa.me/"+WHATSAPP+"?text="+encodeURIComponent(DEMO+t)
